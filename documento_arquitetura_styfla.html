01 Visão do Produto e Personas

A Styfla posiciona-se na vanguarda do mercado de vestuário de Jiu-Jitsu, unindo alta tecnologia de compressão (costura flatlock quádrupla, proteção UV50+, fita de silicone antiderrapante na barra e conformidade com os regulamentos internacionais da IBJJF/CBJJ) à autenticidade estética do streetwear de combate.

Tom de Voz da Marca: Direto, disciplinado, focado em performance e estética autêntica do tatame. Comunicação objetiva, valorizando a resistência dos materiais e o caimento ergonômico no corpo do atleta.

02 Levantamento de Requisitos

Storefront Área do Cliente

  • RF-C01 (Catálogo & Filtros): Filtros por Graduação IBJJF (Branca a Preta), Gênero, Tamanho (PP ao 3XG) e Coleções.
  • RF-C02 (Página do Produto - PDP): Carrossel com fotos em alta resolução, zoom, vídeo do caimento em ação, provador virtual (Peso × Altura) e cálculo instantâneo de frete por CEP.
  • RF-C03 (Cart Drawer): Gaveta lateral de adição assíncrona, barra dinâmica de Frete Grátis e sugestão de cross-sell (ex: bermudas No-Gi).
  • RF-C04 (Checkout Transparente): Fluxo simplificado com PIX (QR Code e Copia-e-Cola em tempo real), Cartão de Crédito e Boleto com busca automática de endereço via CEP.
  • RF-C05 (Painel do Usuário): Linha do tempo de pedidos, rastreamento integrado da transportadora e gestão de múltiplos endereços.

Dashboard Área do Administrador

  • RF-A01 (Métricas de Vendas): Dashboard em tempo real de faturamento, ticket médio, conversão e pedidos pendentes.
  • RF-A02 (Gestão de Produtos & Grade): Cadastro com variantes de cor/faixa e tamanho, upload ordenável de imagens e flags de destaque.
  • RF-A03 (Controle de Estoque): Saldo individual por SKU, alertas automáticos de estoque crítico e log de movimentações.
  • RF-A04 (Gestão de Pedidos): Separação de pedidos (picking list), alteração de status e emissão direta de etiquetas de frete.
  • RF-A05 (Cupons & Promoções): Cupons por valor fixo, percentual, frete grátis e limitação por CPF ou valor mínimo.

Requisitos Não-Funcionais (RNF)

Dimensão Requisito & Métrica Estratégia de Implementação
Performance LCP ≤ 1.2s, FID < 100ms, CLS ≈ 0. Next.js com ISR (Incremental Static Regeneration) para páginas de produto e otimização de imagens WebP/AVIF via next/image.
Segurança PCI-DSS Compliance, HTTPS/HSTS estrito e proteção contra ataques. Tokenização direta no client-side via Gateway de Pagamento (sem armazenar dados de cartão), NextAuth/Auth.js com JWT e Rate Limiting com Redis.
SEO Técnico Indexação imediata e rich snippets de e-commerce. Geração dinâmica de meta-tags OpenGraph, Schema.org (Product, Offer, BreadcrumbList) e sitemap.xml automatizado.
Deploy na VPS Alta disponibilidade, isolamento e recuperação ágil. Docker Compose com builds multi-stage, Nginx Reverse Proxy com SSL Let's Encrypt (Certbot) e backups diários do PostgreSQL via cron para bucket S3.

Regras de Negócio Críticas (RN)

  • RN01 (Cálculo de Frete & Cubagem): Dimensões base da embalagem da rash guard: $25\text{cm} \times 20\text{cm} \times 3\text{cm}$ e peso aproximado de $250\text{g}$. No cálculo de múltiplos itens, a altura é empilhada dinamicamente para a cotação no Melhor Envio/Correios.
  • RN02 (Reserva de Estoque em Checkout Pendente):
    • PIX: O estoque é reservado por 30 minutos. Caso o webhook não receba a confirmação, o pedido é cancelado e o estoque liberado.
    • Boleto: Reserva por 2 dias úteis.
    • Cartão: Baixa imediata na aprovação síncrona da adquirente.
  • RN03 (Prevenção de Venda sem Estoque): É vedada a adição ao carrinho de variantes com saldo zero, exceto produtos configurados expressamente com a flag isPreOrder: true.
  • RN04 (Estornos e Devoluções): De acordo com o CDC (7 dias corridos para arrependimento), o estorno automático via gateway só é liberado antes do despacho, ou após validação física da devolução pelo administrador.

  });

if (process.env.NODE_ENV !== 'production') globalForPrisma.prisma = prisma;

05 Modelagem de Dados Inicial (Prisma)

// packages/database/prisma/schema.prisma

datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

generator client {
  provider = "prisma-client-js"
}

enum Role { CUSTOMER ADMIN STOCK_MANAGER }
enum OrderStatus { PENDING PAID PROCESSING SHIPPED DELIVERED CANCELED REFUNDED }
enum PaymentMethod { PIX CREDIT_CARD BOLETO }
enum PaymentStatus { PENDING AUTHORIZED PAID REFUSED REFUNDED }
enum IbjjfRank { NONE WHITE BLUE PURPLE BROWN BLACK }

model User {
  id           String    @id @default(cuid())
  name         String
  email        String    @unique
  cpf          String?   @unique
  phone        String?
  passwordHash String?
  role         Role      @default(CUSTOMER)
  createdAt    DateTime  @default(now())
  updatedAt    DateTime  @updatedAt
  addresses    Address[]
  orders       Order[]
  cart         Cart?
}

model Address {
  id           String   @id @default(cuid())
  userId       String
  user         User     @relation(fields: [userId], references: [id], onDelete: Cascade)
  recipient    String
  zipCode      String   // CEP
  street       String
  number       String
  complement   String?
  neighborhood String
  city         String
  state        String   // UF
  isDefault    Boolean  @default(false)
  orders       Order[]
}

model Category {
  id          String    @id @default(cuid())
  name        String    // ex: "Rash Guards Masculinas", "No-Gi Shorts"
  slug        String    @unique
  products    Product[]
}

model Product {
  id           String           @id @default(cuid())
  name         String
  slug         String           @unique
  description  String           @db.Text
  details      String?          @db.Text
  categoryId   String
  category     Category         @relation(fields: [categoryId], references: [id])
  ibjjfRank    IbjjfRank        @default(NONE)
  isIbjjfLegal Boolean          @default(false)
  isActive     Boolean          @default(true)
  price        Decimal          @db.Decimal(10, 2)
  pixPrice     Decimal          @db.Decimal(10, 2)
  images       ProductImage[]
  variants     ProductVariant[]
}

model ProductVariant {
  id         String      @id @default(cuid())
  productId  String
  product    Product     @relation(fields: [productId], references: [id], onDelete: Cascade)
  sku        String      @unique // ex: "STY-RG-BLK-M"
  size       String      // "PP", "P", "M", "G", "GG", "2XG"
  stock      Int         @default(0)
  weightG    Int         @default(250) // Peso para frete
  heightCm   Int         @default(3)
  widthCm    Int         @default(20)
  lengthCm   Int         @default(25)
  orderItems OrderItem[]
  cartItems  CartItem[]
}

model Order {
  id              String         @id @default(cuid())
  orderNumber     Int            @unique @default(autoincrement())
  userId          String
  user            User           @relation(fields: [userId], references: [id])
  addressId       String
  address         Address        @relation(fields: [addressId], references: [id])
  status          OrderStatus    @default(PENDING)
  totalAmount     Decimal        @db.Decimal(10, 2)
  subtotal        Decimal        @db.Decimal(10, 2)
  shippingCost    Decimal        @db.Decimal(10, 2)
  shippingCarrier String?
  trackingCode    String?
  items           OrderItem[]
  payment         Payment?
  createdAt       DateTime       @default(now())
  updatedAt       DateTime       @updatedAt
}

model OrderItem {
  id               String         @id @default(cuid())
  orderId          String
  order            Order          @relation(fields: [orderId], references: [id], onDelete: Cascade)
  productVariantId String
  variant          ProductVariant @relation(fields: [productVariantId], references: [id])
  productName      String
  variantInfo      String
  unitPrice        Decimal        @db.Decimal(10, 2)
  quantity         Int
  totalPrice       Decimal        @db.Decimal(10, 2)
}

model Payment {
  id            String        @id @default(cuid())
  orderId       String        @unique
  order         Order         @relation(fields: [orderId], references: [id], onDelete: Cascade)
  method        PaymentMethod
  status        PaymentStatus @default(PENDING)
  transactionId String?
  qrCodePix     String?       @db.Text
  qrCodeUrlPix  String?       @db.Text
  paidAt        DateTime?
  expiresAt     DateTime?
  createdAt     DateTime      @default(now())
}
